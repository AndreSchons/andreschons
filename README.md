<h2 align="center">🏆 Projetos em Destaque</h2>

<h3>🔥 Motor Fiscal Autumn</h3>

**Engine tributário brasileiro — Turborepo Monorepo**

[![Ver Projeto](https://img.shields.io/badge/Repositório-Motor%20Fiscal%20Autumn-2c5364?style=for-the-badge&logo=github&logoColor=white)](https://github.com/AndreSchons)

Motor de cálculo fiscal que faz proxy para a API **Busca Legal**, com cache inteligente por classificação NCM e histórico de simulações por tenant.

<div align="center">
<table>
  <tr>
    <th>Camada</th>
    <th>Tecnologia</th>
    <th>Responsabilidade</th>
  </tr>
  <tr>
    <td>API</td>
    <td>NestJS (porta 3001)</td>
    <td>Motor fiscal, multi-tenancy, cache</td>
  </tr>
  <tr>
    <td>Frontend</td>
    <td>Next.js</td>
    <td>Interface de simulações</td>
  </tr>
  <tr>
    <td>Shared</td>
    <td>TypeScript (@projeto/shared-types)</td>
    <td>Tipos compartilhados no monorepo</td>
  </tr>
  <tr>
    <td>Banco</td>
    <td>PostgreSQL + Prisma (Supabase)</td>
    <td>Persistência e cache de NCM</td>
  </tr>
</table>
</div>

<details>
  <summary><strong>🧠 Destaques Técnicos (clique para expandir)</strong></summary>
  <br>

  - 🔐 **Multi-tenancy** via `x-api-key` com `ApiKeyGuard` e controle por perfil (Admin / Cliente)
  - ⚡ **Cache inteligente** — hash SHA-256 por classificação fiscal, TTL 24h, limpeza automática às 03:00
  - 🧾 **Integração Busca Legal** — parse de XML (atual + reforma tributária), extração de ICMS/IPI/PIS/COFINS/IBS/CBS
  - 🗄️ **Prisma global** como `@Global()` module, disponível em todo o projeto sem reimportação
  - 📦 **Monorepo Turborepo** com separação clara entre `apps/api`, `apps/frontend` e `packages/shared-types`

</details>
